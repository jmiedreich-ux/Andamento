Andamento is distinct and authored. Its light asymmetric tracing-table shell, ruled contribution bands, visible decision ledger, source spine, substantial package sheet, chartreuse owner mark, and contained composer are clearly different from VennuSign's dark signal rail, Google Sheets cells, and the earlier centered transmission log. ## Overall Impression

The interface feels calm, consequential, local, and unusually clear about human authority. Its largest opportunity is to make provenance and approval as inspectable in interaction as they already appear in the visual metaphor.

## What's Working

- The architectural tracing-table metaphor performs a real product job: layers, ruled records, revisions, and owner marks support provenance and authorization.
- Agents remain attributed supporting voices while owner decisions and the package carry the hierarchy.
- Error recovery is exceptional: stale text is preserved, same-field collisions expose both values, and provider failures remain attributed and retryable.

## Priority Issues

1. **P1 — The lineage spine does not prove lineage.** `lineageMarkup()` concatenates message and point codes and slices the result to twelve. Make source → point → package edges explicit, keep all records discoverable, add exact accessible relationship text, and make nodes jump to their source/decision.
2. **P1 — Desktop zoom can replace the entire product with a width notice.** Below 1024 CSS pixels the app shell is hidden. Retain an operable reflowed workspace with a nonblocking support notice so zoomed desktop users are not locked out.
3. **P1 — Immutable approval lacks a verification checkpoint.** Stage an inline confirmation that names the exact version, owner, completeness, source count, irreversibility, and non-execution consequence before recording approval.
4. **P2 — Narrow view removes explicit room navigation.** Keep a compact Rooms return control visible inside the discussion station.
5. **P2 — Microtype and equal-weight point actions add strain.** Raise operational metadata/control type, and group the three dispositions separately from Edit.

## Cognitive Load and Emotional Journey

Wide desktop fails single focus, hierarchy, minimal choices, and working-memory checks; the 1024 tabbed station reduces load. Nine point types and six ledger filters exceed the four-option working-memory target. The emotional opening is calm and trustworthy, conflict recovery is reassuring, and the immutable approved sheet creates a strong ending. The weak valley is manual M/P code matching; the approval edge needs a clearer pre-signing moment.
